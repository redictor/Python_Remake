## Overview

This repository contains personal learning materials for Python. It includes small examples, experiments, and practice code written while studying different language features.

---

## Structure

Each folder represents a topic:

- `dict/` - dictionaries  
- `sets/` - sets  
- `tuple/` - tuples  
- `functions/` - functions  
- `classes/` - OOP, decorators  
- `try-except/` - error handling  
- `files/` - file operations  
- `with as/` - context managers
